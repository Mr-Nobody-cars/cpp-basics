# C/C++ Basics Repository

A basic repository containing fundamental C and C++ programs and examples.

## Contents

### Sample Programs
- `hello_world.c` - Basic Hello World program in C
- `hello_world.cpp` - Basic Hello World program in C++

### Data Structures
- `data_structures/` - Common data structure implementations

### Algorithms
- `algorithms/` - Basic algorithm implementations

## How to Compile and Run

### For C programs:
```bash
gcc hello_world.c -o hello_world
./hello_world
```

### For C++ programs:
```bash
g++ hello_world.cpp -o hello_world
./hello_world
```

## Requirements
- GCC compiler for C
- G++ compiler for C++
